# COMP1238 Midterm Notes

## Week 1 - History
- The first writing was cuneiform: wedge marks pressed into clay tablets in Mesopotamia about 5,000 years ago, mostly used for practical records like receipts
- Babylonians used a positional base-60 number system; Romans used subtractive notation (MCM = 1900)
- Gutenberg's metal movable type press made books far cheaper and helped drive the Renaissance and Reformation
- Monospace fonts come from typewriters and are still used for code

## Week 2 - Bits and Bytes
- A bit is a single 0 or 1, and a byte is 8 bits
- 8 bits store 0 to 255 unsigned, or -128 to 127 signed
- RAM is volatile (lost when power is off); SSDs and HDDs are non-volatile
- ASCII maps numbers to characters, e.g. 65 = 'A'; hexadecimal uses 0-9 and A-F

## Week 3 - Text Structure
- Markdown: `#` for headings, `**bold**`, `_italic_`, `-` for list items
- A backslash escapes special characters in Markdown (`\#`); in HTML use `&lt;`, `&gt;`, `&amp;`
- Unicode gives every character a codepoint written like U+21AA, and UTF-8 is the most common encoding (identical to ASCII for basic characters)

## Week 4 - Keyboards and Editors
- Modifier keys (Ctrl, Shift, Alt) change what other keys do, and touch typing reduces fatigue
- To quit Vim without saving, type `:q!`; VS Code is the most widely used editor
- Regex matches patterns: `line\d+` finds "line" followed by digits
- GitHub Pages builds a website from a repo, with the theme set in `_config.yml`

## Week 5 - CLI
- Basic commands: `ls`, `cd`, `pwd`, `cat`, `cp`, `mv`, `mkdir`
- `grep` searches text with patterns, and pipes/redirection send output to other commands or files
- SSH connects to remote computers securely, and `scp` copies files between them
- The CLI grew out of teletype machines, which is why commands are so short
